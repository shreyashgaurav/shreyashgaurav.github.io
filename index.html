Projects

Duplicate image detection engine

July to September 2026, source on GitHub

A C++20 engine that finds near-duplicate images in large collections. It uses perceptual hashing, SIMD Hamming matching and union-find clustering. A trained nine-feature classifier makes the final call instead of a fixed hash threshold, reaching 97.8% precision and 98.7% recall on 1,200 labelled pairs.

It processes 187 images a second on one thread. When it ran 15 times slower on one machine, profiling showed the cause was cross-filesystem I/O, not the CPU. Corrupt files are logged in a versioned JSON report instead of stopping the run, and 50 tests run under sanitizers in CI.

C++20, Python, CMake, libjpeg-turbo, scikit-learn, GoogleTest

FinDocAI

August 2026 to now, source on GitHub

A question-answering service over SEC 10-K and 10-Q filings and earnings decks. Every answer cites the page it came from. Text is embedded with SBERT and slides with CLIP, so it can retrieve from charts as well as prose.

I'm evaluating it on 40 hand-written questions, measuring Recall@5, answer accuracy and whether it declines unanswerable questions, against a baseline with no retrieval.

Python, FastAPI, SBERT, CLIP, ChromaDB, Gemini, Docker
