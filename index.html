Projects

DejaView

July to September 2026, live demo, source on GitHub
97.8%precision
98.7%recall
187/simages, one thread

A C++ tool that finds duplicate and near-duplicate photos, using a trained model instead of one fixed cutoff. Precision and recall were measured on 1,200 labelled pairs.

A 15× slowdown that wasn't the CPU. Reading photos from a Windows drive through WSL ran at 12 images a second, against 187 on native Linux storage. A release build only helped 1.3×, which showed the work was I/O-bound.

It only reports and never deletes or moves a file. Corrupt files are logged as errors instead of stopping the run, and 50 tests run under sanitizers in CI.

C++20, Python, CMake, libjpeg-turbo, scikit-learn, GoogleTest

FinDocAI

August 2026 to now, source on GitHub

A question-answering service over SEC 10-K and 10-Q filings and earnings decks. Every answer cites the page it came from. Text is embedded with SBERT and slides with CLIP, so it can retrieve from charts as well as prose.

I'm evaluating it on 40 hand-written questions, measuring Recall@5, answer accuracy and whether it declines unanswerable questions, against a baseline with no retrieval.

Python, FastAPI, SBERT, CLIP, ChromaDB, Gemini, Docker
